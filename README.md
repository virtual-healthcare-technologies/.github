# VHT.ai · organization profile and community health files

This repository holds the public-facing files for the **Virtual Healthcare Technologies Inc.** GitHub organization. GitHub applies them across all our public repositories.

| File | What it is |
|---|---|
| [`profile/README.md`](profile/README.md) | The organization profile shown at https://github.com/virtual-healthcare-technologies: what VHT.ai is, where to report things, how we work in the open. |
| [`SECURITY.md`](SECURITY.md) | How to report a security vulnerability (coordinated disclosure, response targets, safe harbour). |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Expected behaviour in our public spaces (Contributor Covenant 2.1). |
| [`SUPPORT.md`](SUPPORT.md) | Where members and developers get help. |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | What contributions we accept and how (translations and reports; app code by invitation). |
| [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) | The template every pull request in our public repos starts from. |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) | Shared issue templates: bug report, feature request, translation fix. Each starts with the required "no personal health information" checkbox. |
| [`LICENSE`](LICENSE) | CC BY 4.0 for the content in our public repositories. |

## Where things happen

- **Bug reports, feature requests, translation fixes:** [virtual-healthcare-technologies/community](https://github.com/virtual-healthcare-technologies/community) → [open an issue](https://github.com/virtual-healthcare-technologies/community/issues/new/choose)
- **Questions, ideas, announcements:** [Community Discussions](https://github.com/virtual-healthcare-technologies/community/discussions)
- **Security reports:** echna@vht.ai (see [SECURITY.md](SECURITY.md)). Please do not open a public issue.
- **Everything else:** echna@vht.ai

## One rule above all

**Never post personal health information** in issues, discussions or pull requests. Describe the problem without the data. See the [community README](https://github.com/virtual-healthcare-technologies/community#readme) for details.

> VHT.ai is in beta. It provides educational guidance only and is not a substitute for professional medical advice, diagnosis or treatment.
